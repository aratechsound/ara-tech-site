# Formal confirmation v3

The approved v3 layout is connected to the existing formal-contract API and immutable JSON snapshot. The brand is the Production HOME/mail color `#007bff` and `/img/ara-tech-logo-horizontal-white.png`. No schema migration or existing-offer update is required.

## Issuance and document binding

- One mandatory final quote retains the existing sent-to-customer Gmail binding, frozen original bytes and SHA-256 checks.
- Related PDF candidates are case-linked incoming/outgoing Gmail attachments. No candidate is automatically selected. Administrators inspect selected files before issuance.
- Each selected related file is frozen in `snapshot.related_documents` with its distinct `related` role, Gmail message/attachment ID, file ID, filename, MIME type, byte length, SHA-256 and original `content_base64`. Related material is not a price/scope basis.
- The server re-fetches and validates identities/hashes at issuance, rejecting duplicate documents (including the final quote), mismatched hashes, cross-case attachments, unsafe PDFs, more than five related documents or a combined related size above 1,500,000 bytes. The existing per-PDF 1.5 MB / 30-page safety checks remain.
- Public and admin-list JSON responses omit related content bytes. The public `related_document` action uses only frozen bytes after token validation, and verifies SHA-256 before serving. Gmail edits cannot replace issued material.
- Acceptance preserves the complete issued snapshot using the existing atomic DB function and hash check. Receipt PDFs retain full terms, the actual due date and related identity/hash metadata. Only the mandatory final quote is appended as the price-basis PDF; its byte-exact embedded original remains unchanged.

## Payment date and legacy behavior

- Standard new issuance fixes event date + 14 days, advanced to the next Japanese bank business day, with a calendar-version stamp and nominal date.
- The included Cabinet Office calendar covers 2026 and 2027. Weekends, national/substitute holidays and December 31-January 3 are excluded. Source: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html . Unpublished years fail closed; update the calendar before standard issuance for those years.
- A payment exception requires explicit administrator approval, custom text and an exact approved date no earlier than the event. Standard 14-day text is replaced, not added contradictorily.
- Read-only `preview_conditions` displays the server-computed full future-issuance conditions and never issues/revokes an offer.
- Old snapshots are never backfilled. The page uses their original payment/cancellation/full terms and does not calculate a new deadline or add related tabs. Presentation v3's compact dates require stored cancellation bands.
- The terms scroll container is for readability, not a consent gate. Existing name/checkbox, token, snapshot-hash and atomic acceptance controls remain.

## Email and verification

The Gmail reply preview uses the exact server `preview.html` generated by the same renderer as the final MIME HTML. The visible iframe uses `sandbox="allow-same-origin"` without scripts/forms/popups/top-navigation permission; plain text is supplementary and collapsed. Its full-width layout and explicit visibility avoid blank/hidden preview presentation. No send path or transport is changed.

Run `node tests/validate-pa-contract-v3.cjs`, the existing contract/customer tests and the full `tests/validate-*.cjs` suite. The isolated browser test is `tests/browser/pa-contract-v3.cjs` (Playwright + local Edge; set `PA_CONTRACT_OUTPUT_DIR` for screenshots). It denies external network, exercises actual Production page JS/CSS/CSP, verifies 1440/390 widths, PDF switching, legacy content, explicit admin selection and actual email-preview function/HTML. It never accepts or sends. Other regression tests exercise acceptance/transport only inside synthetic fixtures.

Production verification for this release must not issue, revoke or accept any Takebayashi URL. Future Takebayashi reissuance is a separate authorized operation after this deployment passes.
